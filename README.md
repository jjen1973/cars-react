# Cars React

React + TypeScript version of the Cars class project, built with Vite.

## Local development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and add your EmailJS values to enable the contact form.

## Deploy to Vercel

Import the GitHub repository into Vercel. Vercel detects Vite automatically. Add the three `VITE_EMAILJS_*` variables in the Vercel project settings, then deploy.
